## The five questions
1. **Enter:** `import kubernetes` — library. Generated `*Api` classes are the HTTP surface to the apiserver.
2. **Data:** the cluster. No local store.
3. **Talks to:** Kubernetes apiserver; generator talks to swagger.
4. **Add a feature:** handwritten helper → `kubernetes/base` / `utils` / `informer`. New API object → spec in Kubernetes main + `scripts/update-client.sh`, not a hand-edit under `client/api/`.
5. **Scared to touch:** generated client (wiped on regen); `ws_client.py` / informer (watch correctness); hotfixes that disagree with the generator.
